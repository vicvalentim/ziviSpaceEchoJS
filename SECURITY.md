# Security Policy

ziviSpaceEcho is distributed as a REAPER JSFX source file.

If you find a security-relevant issue, please do not open a public issue with exploit details. Instead, contact the maintainer privately through the contact channels listed in the repository profile or documentation site.

## Supported versions

The latest public release is the supported version.

## Scope

Relevant reports may include:

- unsafe file handling;
- unexpected execution behavior;
- malicious or suspicious code introduced through contributions;
- supply-chain or release integrity concerns.
