# Guía de diseño sonoro

## Slap vocal clásico

```text
Mode: 1 o 5
Timing: Manual ms
Manual Time: 90–140 ms
Intensity: 10–25%
Echo Volume: 20–40%
Drive: 5–15%
Noise: 0–8%
```

## Dub feedback wash

```text
Mode: 8, 9, 10 o 11
Timing: RE-201 Motor
Intensity: 55–85%
Echo Volume: 45–70%
Bass: +1 a +4 dB
Treble: -2 a -6 dB
Condition: +10 a +40
W/F: +10 a +35
Master: -6 dB o menos
```

## Reverb only

Usa la posición 12.
