# Guía de diseño sonoro

## Slap vocal clásico

```text
Mode: 1 o 5
Timing: Manual ms
Manual Time: 90–140 ms
Intensity: 10–25%
Echo Volume: 20–40%
Drive: 5–15%
Noise: 0–8%
```

## Dub feedback wash

```text
Mode: 8, 9, 10 o 11
Timing: RE-201 Motor
Intensity: 55–85%
Echo Volume: 45–70%
Bass: +1 a +4 dB
Treble: -2 a -6 dB
Condition: +10 a +40
W/F: +10 a +35
Master: -6 dB o menos
```

## Echo ambiente con muelles

```text
Mode: 7, 8, 9 o 11
Reverb Volume: 35–65%
Dwell: 35–60%
Decay: 50–80%
Drip: 10–35%
Bounce: 25–55%
Grain: 20–45%
```

## Cinta sucia

```text
Drive: 25–55%
Noise: 12–30%
Condition: +35 a +70
Tape Age: Old
Loop Length: Short o RT-1
High Cut: valores negativos
```

## Reverb only

Usa la posición 12.
