# Guia de desenho sonoro

## Slap vocal clássico

```text
Mode: 1 ou 5
Timing: Manual ms
Manual Time: 90–140 ms
Intensity: 10–25%
Echo Volume: 20–40%
Drive: 5–15%
Noise: 0–8%
```

## Dub feedback wash

```text
Mode: 8, 9, 10 ou 11
Timing: RE-201 Motor
Intensity: 55–85%
Echo Volume: 45–70%
Bass: +1 a +4 dB
Treble: -2 a -6 dB
Condition: +10 a +40
W/F: +10 a +35
Master: -6 dB ou menor
```

Ajuste `Repeat Rate` e `Intensity` com cuidado.

## Echo ambiente com mola

```text
Mode: 7, 8, 9 ou 11
Reverb Volume: 35–65%
Dwell: 35–60%
Decay: 50–80%
Drip: 10–35%
Bounce: 25–55%
Grain: 20–45%
```

## Loop de fita sujo

```text
Drive: 25–55%
Noise: 12–30%
Condition: +35 a +70
Tape Age: Old
Loop Length: Short ou RT-1
High Cut: valores negativos
```

## Delay limpo de produção

```text
Timing: Tempo Sync
Intensity: 20–40%
Echo Volume: 30–50%
Drive: 0–10%
Noise: 0–5%
Condition: -20 a 0
Stereo Mode: Dual
```
