# Use of Generative AI

ziviSpaceEcho declares the use of generative artificial intelligence tools in its development, documentation and release-organization process.

This page is intended for users, citers, reviewers, researchers and repository visitors who need to understand how AI assistance was used and how authorship responsibility is assigned.

## Summary

- **Human author:** Victor Hugo Soares Valentim.
- **Generative AI tools used:** GitHub Copilot; ChatGPT (GPT-5.5 Thinking) by OpenAI.
- **Role of AI:** assistive support for coding, code review, development discussion, documentation, release organization and metadata preparation.
- **Authorship status of AI:** not an author, co-author, creator, maintainer or copyright holder.
- **Responsibility:** the human author reviewed, edited, validated and approved the final repository content.
- **Runtime behavior:** the plugin does not include or call generative AI.

## Authorship and responsibility

ziviSpaceEcho was conceived, directed, reviewed and published by Victor Hugo Soares Valentim.

Generative AI tools were used as assistive instruments. They are not listed as authors, co-authors, creators, maintainers, copyright holders or citation authors.

The human author remains responsible for:

- artistic and technical decisions;
- source-code review;
- DSP behavior validation;
- documentation review;
- repository organization;
- release approval;
- citation metadata;
- public dissemination;
- any errors, omissions, inaccuracies, plagiarism or problematic outputs that may have originated from AI-assisted work.

## Declared uses

Generative AI was used to support:

- discussion of software architecture and implementation strategies;
- code completion and coding assistance;
- code review and debugging support;
- JSFX implementation analysis;
- interface logic review;
- documentation drafting and editing;
- README organization;
- changelog organization;
- GitHub release preparation;
- Zenodo metadata preparation;
- citation metadata preparation;
- repository-governance files;
- editorial revision of technical descriptions.

## What AI does not do in this project

Generative AI is not embedded in the plugin.

The JSFX plugin does not call an AI model, does not depend on an AI service and does not transmit user audio, user sessions or REAPER project data to an AI provider.

The released plugin runs locally in REAPER according to the source code distributed in this repository.

## Confidentiality and third-party material

No confidential peer-review material, unpublished third-party research project or third-party proposal was intentionally submitted to generative AI tools for evaluation, review or decision-making.

The project avoids presenting AI-assisted content as if it were unreviewed human-only output. AI assistance is explicitly disclosed here and in the repository root file `AI_USAGE.md`.
