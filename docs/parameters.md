# Parameter Reference

## Mode and timing

| Control | Range / Values | Description |
|---|---|---|
| Mode Selector | 1–12 | Selects playback heads and reverb routing. |
| Timing Mode | Motor / Manual / Sync / Tap | Selects the delay-time strategy. |
| Repeat Rate | 0–100% | Motor-speed style control. |
| Manual Time | 20–2000 ms | Leading head time in manual mode. |
| Sync Division | 2/1 to 1/32 | Tempo-synchronized division. |

## Echo / Mix

| Control | Default | Description |
|---|---:|---|
| Intensity | 35% | Feedback/repeat intensity. |
| Echo Volume | 45% | Echo branch output level. |
| Reverb Volume | 22% | Spring reverb branch output level. |

## Tape tone

| Control | Default | Description |
|---|---:|---|
| Bass | 0 dB | Echo-only bass tone shaping. |
| Treble | 0 dB | Echo-only treble tone shaping. |
| Drive | 10% | Preamp/tape drive amount. |
| Noise | 8% | Tape noise amount. |

## Input stage

| Control | Values | Description |
|---|---|---|
| Input | Instrument / P.A. Send / Mic | Input behavior selection. |
| Input Level | -24 to +18 dB | Record/input gain. |
| Instrument Echo Switch | Echo / Dry | Instrument echo behavior. |
| Echo Cancel | FX On / Cut | Effect cancel behavior. |

## Motor / Wow-Flutter

| Control | Range | Description |
|---|---:|---|
| Condition | -100 to +100 | General tape/machine condition. |
| W/F Discrepancy | -100 to +100 | Wow/flutter discrepancy behavior. |
| Motor Torque | -100 to +100 | Motor response/torque character. |
| LFO Depth | 0–100% | Tape speed LFO modulation depth. |
| LFO Rate | 0.05–12 Hz | Tape speed LFO rate. |
| LFO Wave | Sine / Triangle / Ramp / Square / Random | Tape speed modulation waveform. |

## Filters

| Control | Range | Description |
|---|---:|---|
| Low Cut | -100 to +100 | Playback head low-cut behavior. |
| High Cut | -100 to +100 | Playback head high-cut behavior. |

## Tape media

| Control | Values | Description |
|---|---|---|
| Tape Formula | Ampex 456 / 3M 996 | Tape formula voicing. |
| Tape Age | New / Old | Tape age voicing. |
| Loop Length | 36 / 72 / 120 in | Virtual tape-loop length behavior. |

## Spring tank

| Control | Default | Description |
|---|---:|---|
| Dwell | 35% | Excitation/drive into spring branch. |
| Decay | 45% | Spring tail length. |
| Drip | 20% | Spring drip/transient character. |
| Bounce | 35% | Spring movement/bounce. |
| Grain | 30% | Granular spring texture. |

## Reverb shape

| Control | Default | Description |
|---|---:|---|
| Reverb Bass | 0 dB | Bass shaping for spring branch. |
| Reverb Treble | 0 dB | Treble shaping for spring branch. |

## Output

| Control | Values | Description |
|---|---|---|
| Output | L / M / H | Output-level behavior. |
| Stereo Mode | Single / Dual | Original-like single mode or dual stereo mode. |
| Master | -24 to +12 dB | Final output gain. |
