# Screenshot Capture Guide

Use this folder for images referenced by the README and GitHub Pages manual.

Recommended files:

```text
screenshot-main.png
screenshot-header.png
screenshot-mode-selector.png
screenshot-main-grid.png
screenshot-editor.png
screenshot-bottom-bar.png
screenshot-reaper-track.png
```

## Suggested capture process

1. Load the plugin in REAPER.
2. Resize the FX window until the full interface is visible.
3. Capture at high resolution.
4. Export PNG files.
5. Replace the placeholder references.
