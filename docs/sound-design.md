# Sound Design Guide

## Classic vocal slap

```text
Mode: 1 or 5
Timing: Manual ms
Manual Time: 90–140 ms
Intensity: 10–25%
Echo Volume: 20–40%
Drive: 5–15%
Noise: 0–8%
```

## Dub feedback wash

```text
Mode: 8, 9, 10 or 11
Timing: RE-201 Motor
Intensity: 55–85%
Echo Volume: 45–70%
Bass: +1 to +4 dB
Treble: -2 to -6 dB
Condition: +10 to +40
W/F: +10 to +35
```

Ride `Repeat Rate` and `Intensity` carefully.

## Ambient spring echo

```text
Mode: 7, 8, 9 or 11
Reverb Volume: 35–65%
Dwell: 35–60%
Decay: 50–80%
Drip: 10–35%
Bounce: 25–55%
Grain: 20–45%
```

## Dirty tape loop

```text
Drive: 25–55%
Noise: 12–30%
Condition: +35 to +70
Tape Age: Old
Loop Length: Short or RT-1
High Cut: negative values
```

## Clean production delay

```text
Timing: Tempo Sync
Intensity: 20–40%
Echo Volume: 30–50%
Drive: 0–10%
Noise: 0–5%
Condition: -20 to 0
Stereo Mode: Dual
```

## Reverb only

Use position 12.

```text
Mode: 12 Reverb Only
Reverb Volume: as needed
Dwell: 20–50%
Decay: 35–75%
Drip: 5–30%
```

Position 12 is marked with a blue LED.
