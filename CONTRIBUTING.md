# Contributing to ziviSpaceEcho

Thanks for your interest in ziviSpaceEcho.

This repository currently prioritizes stability, documentation and reproducible releases. Contributions are welcome, especially in the following areas:

- bug reports;
- REAPER compatibility notes;
- documentation corrections;
- audio examples and presets;
- interface usability feedback;
- performance observations.

## Development notes

The main plugin file is:

```text
src/ziviSpaceEcho.jsfx
```

The versioned release copy is:

```text
src/ziviSpaceEcho_v7_6_2.jsfx
```

Please avoid changing DSP behavior without clearly documenting the change.

## Reporting bugs

When reporting a bug, include:

- operating system;
- REAPER version;
- ziviSpaceEcho version;
- sample rate and block size, if relevant;
- steps to reproduce;
- expected behavior;
- actual behavior.

## Pull requests

Before opening a pull request, please describe:

- what changed;
- why the change is needed;
- whether DSP behavior changed;
- whether documentation needs to be updated.
