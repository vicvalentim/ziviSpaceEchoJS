This declaration is provided for transparency, research integrity, repository users, software citers and institutional compliance.

- GitHub Copilot;
- ChatGPT (GPT-5.5 Thinking) by OpenAI.

## Declared purposes

Generative AI was used to support the following activities:

- discussion of software architecture and implementation strategies;
- code completion and coding assistance;
- code review and debugging support;
- JSFX implementation analysis;
- interface logic review;
- documentation drafting and editing;
- README organization;
- changelog organization;
- GitHub release preparation;
- Zenodo metadata preparation;
- citation metadata preparation;
- repository-governance files;
- editorial revision of technical descriptions.

## Scope and limitations

Generative AI was used during the development and documentation workflow only.

Generative AI is not embedded in the plugin. The plugin does not call, depend on, or communicate with any generative AI service at runtime.

The released JSFX file runs locally in REAPER according to the source code distributed in this repository.

## Human review

All AI-assisted outputs were reviewed, edited and approved by the human author before inclusion in the repository.

No AI-generated output was accepted automatically. The human author evaluated the material according to the project’s artistic, technical, academic and ethical requirements.

## Confidentiality and third-party material

No confidential peer-review material, unpublished third-party research project or third-party proposal was intentionally submitted to generative AI tools for evaluation, review or decision-making.

Any references to existing products, technologies or trademarks are used only for contextual and descriptive purposes, and do not imply affiliation, endorsement or authorization.

Generative AI was used as an auxiliary tool. It did not replace human authorship, scholarly responsibility, technical validation or creative decision-making.
